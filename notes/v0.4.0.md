# v0.4.0 - round-mask margins, row actions, the Play pipeline

The served side of this release is small - the icon shrank11% so
round launcher masks keep their margin (verified through a round-mask
render, nothing clipped). The rest rides the same tag because it
ships together: the Android app's file-manager layer and the store
pipeline.

## What changed

- **Icons** (`frontend/assets/icons/`): the cloud runs at
  CLOUD_SCALE1.25 with the fx at FX_SCALE0.71 - same artwork, more
  margin. Regenerated by `gen-icons.js`, pinned by the suite.
- **App** (the `fxcloud-debug-apk` artifact of this tag): a per-row ⋮
  menu (share, copy, move, delete), long-press multi-select with its
  own action bar carrying the same four actions, and the trash view
  (restore, purge, empty) behind the header's Trash entry.
- **Play pipeline**: the upload key lives in the repository secrets
  (never the repo itself); the new `android-aab` CI job attaches a
  signed `fxcloud-<tag>.aab` to every release, verified against the
  upload key's fingerprint.

## Compatibility

Icons only for the server: no API, no JavaScript, no data, no
manifest change. The AAB and the app are additive - the static
binary and existing installs are untouched.

## Tests

Suite stays at **879 checks**, `cargo test` at90, the JVM vectors at
15. The AAB signature was verified against `B0:F9:E8:24:...:3A:EC`
before the pipeline shipped.
