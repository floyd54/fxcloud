# v0.4.2 - the version history, and the light-blue canvas

An app release for the Play closed test: the last S5 slices plus the
light-mode identity the store banner introduced.

- **Versions** (S5c): "Versions" in the per-row menu (files only)
  opens every kept save of a file with its time, size and an
  "encrypted" marker for the eras that were ciphertext. View runs
  through the normal preview from the version's own bytes - a save
  from the plaintext era stays plaintext even under today's
  encrypted row - Restore reloads both views like the web does,
  Delete sits behind a confirmation. Rotate is hidden there: it acts
  on the current file, not on a stand.
- **Create from the path bar**: the "+" menu makes a folder or an
  empty file in the current directory, straight from the web's
  shapes (`POST /api/files/folder`, `POST /api/files/file`).
- **Light-blue canvas**: in light mode every screen now paints the
  feature graphic's field (`#D5EEFB`) - login, tree, dialogs,
  preview, trash, settings, versions - with the primary accent
  darkened to the shadow blue (`#00598F`) so links and buttons keep
  their contrast on it. Dark mode is untouched: the blue would not
  read on dark. The login form gained the mark as its hero: the
  store banner's cloud+fx above the fields.
- **Store paperwork**: privacy policy, imprint, terms of service and
  the data-deletion request page live as GitHub Pages, the feature
  graphic (1024x500) sits in `docs/`, and every release now carries
  the debug APK next to the AAB.

## Compatibility

The server binary is unchanged apart from its version string; no API,
no data, no manifest change.

## Tests

Suite stays at **879 checks**, `cargo test` at 90, the JVM vectors at
15. The bundle ships as **versionCode 6** - above the closed track's
current 5, so Play takes it as an update; uploading it during the
test does not reset the 14-day counter (that tracks tester opt-in,
not builds).
