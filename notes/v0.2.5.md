# v0.2.5 - the toolbar fits the phone

Buttons like "Upload folder" and "New group folder" took a whole row
of a small screen - and the touch-target sizing of v0.2.3 had made
them wider still. The toolbar is now icon-first on phones.

## What changed

- **Icon-only toolbar at <=640px.** Glyph and label moved into
  separate spans: the label hides on phones, the glyph stays - a bit
  larger (18px) on a 44px floor - and the row collapses from five
  wide chips to icon-sized squares. Desktop keeps the exact button
  it always had (glyph, space, label).
- **Every file-action button carries a title.** `data-i18n-title` and
  `data-i18n-aria` on all seven buttons: a hover tooltip with the
  mouse, a long-press tooltip on Android, and the button's name for
  screen readers - the same dictionary key that shows on desktop.
- **Labels are glyph-free.** The `+`/`up` prefixes moved out of the
  four button keys in all three tables (de/en/tlh), so a label is a
  label everywhere and an icon is an icon; the suite pins both halves
  (dictionary has no glyphs, spans exist, titles cover every button).
- **Secondary buttons keep their labels** (Trash, Empty trash): they
  are the only buttons on the trash screen and the long German
  strings deserve the room - the "primary icon, secondary plain"
  hierarchy rule is untouched.

## Compatibility

HTML, i18n values and CSS only: no API, session, format or crypto
change. Dictionary keys are unchanged (only their values shed the
glyph prefix), so translations and the i18n parity check are
unaffected.

## Tests

The suite grew by4 checks to **844**: the glyph/label spans on every
primary button, title coverage (6 `files.*` + `group.newFolder`),
glyph-free labels in all three tables, and the icon-only CSS rules;
the two exact-markup greps were re-aimed at the new button structure
(the "primary icon, secondary plain" hierarchy check passes
unchanged). `cargo test` stays at73. Every gate (fmt, clippy with
warnings denied, qjsc, call arity, i18n parity across de/en/tlh) runs
before the tests on every push.
