# v0.2.6 - toolbar icons you can tell apart

v0.2.5 made the toolbar icon-only on phones - but the "icons" were
the old text glyphs: two `+` and two `up arrows`, indistinguishable
once the labels were gone. This release replaces them with real
symbols, for every button.

## What changed

- **Eight distinct inline SVG icons**: page with plus (New file),
  folder with plus (New folder), folder with a person (New group
  folder), page with up-arrow (Upload file), folder with up-arrow
  (Upload folder), wastebasket (Trash), wastebasket with an X (Empty
  trash) and an eye (Show hidden). They share the stroke style and
  `currentColor` behaviour of the gallery arrows the app already had,
  so they follow the button's colors on blue and on white alike.
- **Trash and Show hidden carry a symbol for the first time.** Every
  toolbar button is now icon + label on desktop and icon-only at
  <=640px, with the existing title as tooltip (long press on touch,
  hover with a mouse). The old "primary carries an icon, secondary is
  plain" rule was tied to text glyphs and moves with them; the
  bulkbar keeps its glyph hierarchy untouched (download/restore get
  the symbol, Move/Copy/Share stay plain).
- **The drawing trap is documented in the markup**: SVG path
  coordinates need explicit separators (`M12 9.5`, never `M129.5`) -
  Chromium reads the compact form as one number and silently drops
  the path, which renders an empty icon. No parser we run can catch
  that (they all accept both forms), so the comment above the
  toolbar is the guard; the icons were verified by screenshot from a
  real instance.

## Compatibility

HTML, one CSS block and suite checks only: no JavaScript, API,
session, i18n-key or crypto change. Labels and titles are unchanged,
so the three translation tables are untouched.

## Tests

The suite stays at **844 checks** with the structure checks re-aimed:
every toolbar button owns an SVG plus a label span (8/8), the seven
file-action titles plus the group title cover every button, the
dictionary stays glyph-free, and the Perl hierarchy check now demands
an SVG per toolbar button while keeping the bulkbar's old rule.
`cargo test` stays at73. Every gate (fmt, clippy with warnings denied,
qjsc, call arity, i18n parity across de/en/tlh) runs before the tests
on every push.
