# v0.3.5 - the final mark: offset double cloud

The icon settles after two feedback rounds: light blue field, front
cloud in the accent blue with the white fx, and the shadow as what it
was described to be - a second cloud in #00598F, offset down-left, as
if the cloud were lit from the upper right. PWA icons and the Android
launcher icon carry the same picture (verified side by side). This
supersedes v0.3.4's soft blur, which never shipped to an installed
instance.

## What changed

- **Icons**: all five PWA icons regenerated by
  `frontend/tests/gen-icons.js`; the generator draws the back cloud
  first (same shape, five units left, six down), the front cloud over
  it, the fx on top. The Android foreground mirrors it with one solid
  offset path.

## Compatibility

Icons only: no API, no JavaScript, no data, no manifest change. A
home-screen shortcut picks the new icon up with the next manifest
refresh; re-add the shortcut if the browser holds on to the old one.

## Tests

Suite stays at **879 checks** including the pixel-level icon check;
`cargo test` stays at 90. The honest verifier is a look at the tab
icon and the home-screen shortcut after this update.
