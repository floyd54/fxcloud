# v0.4.1 - target API36, and the settings screen

A compliance release for the store plus the S5b app work that rides
along:

- **Play raised the floor**: the console rejects bundles targeting
  API35 ("must target at least API level36"). The app now targets
  **API36** (compileSdk was already36) with **versionCode5** - the
  rejected v0.4.0 bundle holds code4. The native library already met
  the 16 KB page-size rule (every LOAD segment at0x4000, NDK29
  default), so nothing else moved.
- **App settings** (the `fxcloud-debug-apk` of this tag): display
  name, theme (system/light/dark - the server's value over the device
  default), the auto-unlock switch with its local blob handling, and
  the password change - the web's settings dialog, on the phone.

## Compatibility

The server binary is unchanged apart from its version string; no API,
no data, no manifest change.

## Tests

Suite stays at **879 checks**, `cargo test` at90, the JVM vectors at
15. `aapt2` confirms `targetSdkVersion36` on the built APK, and the
AAB's signature still matches the upload key.
