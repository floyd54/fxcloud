# v0.3.2 - the dark strip in the file list is gone

A one-hunk release: in dark mode the file list's header strip (Name,
Size, Modified - and the select-all box over every file) carried a light
gray from before the theme existed, so it glowed white across the
listing. It now follows the panels like every other surface. The same
leftover in one more place went with it: the editor's markdown code
chips kept their light background in dark mode, which left light text on
a light chip.

## What changed

- **Dark mode**: the list header strip and the editor's code chips are
  theme-aware now (`frontend/assets/style.css`, two dark-only rules -
  light mode is untouched). The office frame stays paper-white on
  purpose: an office document is paper, as its comment says.

## Compatibility

Pure CSS, dark mode only: no API, no JavaScript, no data, nothing
changes in light mode.

## Tests

The suite stays at **879 checks**, `cargo test` at 90, every gate runs
as before. The fix is visual, so the honest verifier is a dark-mode
look at the file list: the header now sits on the panel color, like the
bulk bar below it.
