# v0.3.3 - the new mark: a cloud with fx

The launcher and PWA icons got the redesign the native Android app
carries (phase 7): a dark gradient, the brand cloud as a soft blue
with a brighter rim, and a white "fx" inside. The old artwork also had
a stray blob in every top-left corner - a base box drawn at the
coordinate origin instead of under the cloud - which the redesign
takes with it.

## What changed

- **Icons**: all five PWA icons (32/192/512/maskable/180) show the
  cloud+fx mark now (`frontend/assets/icons/`), byte-for-byte what
  `frontend/tests/gen-icons.js` renders - the artwork lives in the
  script, the PNGs stay pinned against it.
- **Generator**: `render()` composites the gradient, then the cloud
  (fill 45% / rim 70% of the accent #0082c9 - the same AARRGGBB
  values the Android XML carries), then the fx as seven stroked
  segments; the dead base box is gone.

## Compatibility

Icons only: no API, no JavaScript, no data, no manifest change - every
filename stays as it was. A home-screen shortcut picks the new icon up
with the next manifest refresh; if the browser holds on to the old
one, remove the shortcut and add the site again.

## Tests

The suite stays at **879 checks**, including the pixel-level icon
check (`gen-icons.js --check`); `cargo test` stays at 90. The honest
verifier is a look at the tab icon and the home-screen shortcut after
this update.
